## 比较口径

仅在比较键中对文本值执行 Python Unicode `casefold()`。WHERE 条件按多重集比较，忽略 AND 顺序但保留重复次数；列、运算符和值类型均保留。不消除标点、空格或引号，也不改写数字。只有公共 Gold 条件筛出至少一行，且额外条件在这些行上全部为真，才判当前表上的冗余。这不是普遍逻辑等价证明。
